# Semaphore 2K26 — Rules & Regulations

A React (Vite + JavaScript) page recreating the rules poster with your requested changes:
- Title changed to "Semaphore 2K26"
- "Hear ye! Hear ye!" removed
- Subtitle simplified to "Rules & Regulations"

## Run locally

```bash
npm install
npm run dev
```

Then open the URL shown in the terminal (usually http://localhost:5173).

## Build for production

```bash
npm run build
```

Output goes to the `dist/` folder — upload that anywhere (Netlify, Vercel, GitHub Pages, etc.).

## Edit the rules

Open `src/App.jsx` and edit the `rules` array at the top of the file.
